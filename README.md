# Learn with Miss Walaa — English · Class 2/B

## الرفع على GitHub Pages (مرة واحدة)

1. اعملي ريبو جديد على GitHub باسم **miss-walaa-english** (Public).
2. Add file → Upload files → اسحبي **كل اللي جوه الفولدر ده** (index.html · manifest.webmanifest · sw.js · icons · assets).
3. Commit changes.
4. Settings → Pages → Source: **Deploy from a branch** → Branch: **main** / **(root)** → Save.
5. بعد دقيقة اللينك يبقى:
   `https://اسم-حسابك.github.io/miss-walaa-english/`

## التثبيت على الموبايل

- **أندرويد (Chrome):** افتحي اللينك → زرار «Install the app» في الشاشة الأولى → Install.
- **آيفون (Safari):** افتحي اللينك في Safari → Share ⬆︎ → Add to Home Screen → Add.

## الصوت

- أول لمسة في التطبيق بتفتح الصوت (ده شرط الموبايل).
- لو الصوت مش طالع على الآيفون: شيلي وضع الصامت (الزرار اللي على الجنب) وعلّي الصوت.
- الصوت بيستخدم أصوات الموبايل نفسه، فشكله بيختلف من جهاز للتاني.

## لو عدّلتي حاجة بعدين

ارفعي index.html الجديد مكان القديم. لو الموبايل لسه بيفتح النسخة القديمة: اقفلي التطبيق وافتحيه تاني مرتين.
